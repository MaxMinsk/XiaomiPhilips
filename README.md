# Xiaomi Philips EyeCare for Home Assistant

Локальная интеграция для **`philips.light.sread2`**. Настройка по IP и miIO-токену через интерфейс Home Assistant, без аккаунта Xiaomi и приложения Mi Home.

Первая версия: **0.1.0**. Целевая версия **Home Assistant Core 2026.9.1 / Python 3.14**. Реальная лампа ещё требует проверки пользователем: ответы сети в автоматических тестах подменяются. Поддержку других моделей не заявляем.

## Возможности

- Отдельное устройство в HA со стабильной идентификацией по MAC.
- Основной свет: включение, выключение, яркость.
- Подсветка (Ambient Light): включение, выключение, яркость.
- Общий опрос обоих источников света каждые 15 секунд.
- Статус недоступности при потере связи и повторные попытки подключения.
- Изменение IP и токена через «Перенастроить» в меню интеграции.
- Русский и английский интерфейс, диагностика без токена и адреса.

Пока не реализованы режим EyeCare, сцены, напоминания, таймер выключения и автоматический ночник. Цвет и цветовая температура не заявляются.

## Установка через HACS

1. Откройте **HACS → меню ⋮ → Пользовательские репозитории / Custom repositories**.
2. Добавьте `https://github.com/MaxMinsk/XiaomiPhilips`, категория **Integration / Интеграция**.
3. Найдите **Xiaomi Philips EyeCare** и скачайте последнюю версию.
4. Перезапустите Home Assistant.
5. Откройте **Настройки → Устройства и службы → Добавить интеграцию → Xiaomi Philips EyeCare**.
6. Введите IP лампы в домашней сети, miIO-токен из 32 шестнадцатеричных символов и название лампы.

Токен вводится без `b`, кавычек и пробелов. Адрес — без `http://` или `https://`. Устройство и обе сущности создаются после проверки связи и чтения состояния лампы. YAML для этой интеграции не нужен.

В HACS можно устанавливать обновления из этого репозитория. После обновления перезапустите HA. Иконка поставляется вместе с интеграцией и не требует регистрации в каталоге Home Assistant Brands.

## Переход со старой интеграции

Сначала сохраните старую конфигурацию. После успешной проверки новой интеграции удалите только блок этой лампы с `platform: xiaomi_miio_philipslight` из YAML и перезапустите HA. Если в `light:` есть другие лампы, оставьте их.

Новые сущности получают собственные идентификаторы. Автоматизации и карточки, ссылающиеся на старые сущности, необходимо переключить на новые. Одновременный опрос старой и новой интеграцией лучше оставить только на время проверки.

## Подготовка лампы

Лампа уже должна быть подключена к домашнему Wi-Fi. Первичная передача SSID/пароля выполняется отдельно, например через `python-miio` и `Device.configure_wifi`. Эта интеграция не меняет Wi-Fi и прошивку лампы.

HA должен иметь сетевой доступ к лампе по UDP 54321. Рекомендуется закрепить IP лампы в DHCP. При сбросе лампы токен может измениться.

Управление выполняется по локальному miIO. Интернет нужен для установки зависимостей и обновлений HACS; аккаунт Xiaomi для управления не используется. Это не меняет сетевое поведение заводской прошивки самой лампы.

## Если не работает

- **Интеграции нет в поиске:** убедитесь, что HACS скачал её и HA был перезапущен. При необходимости обновите страницу браузера.
- **Нет связи / cannot connect:** проверьте IP, токен, VLAN, гостевую сеть и изоляцию клиентов. Тайм-аут может означать как сетевую проблему, так и неверный токен.
- **Неполные данные:** прошивка вернула неожиданный набор свойств. Пришлите модель, версию прошивки и сообщение ошибки в Issues.
- **Лампа недоступна:** после восстановления сети интеграция повторит опрос автоматически. При изменении IP используйте «Перенастроить».

Журналы: **Настройки → Система → Журналы**, поиск `philips_eyecare`. Диагностику можно скачать из меню интеграции; она не содержит токена, IP или MAC. Не публикуйте токен и полный конфигурационный файл. Не включайте подробное логирование библиотеки `miio` перед публикацией журналов: библиотека может выводить протокольные данные.

## Проверка и разработка

```sh
python3.14 -m venv .venv
.venv/bin/python -m pip install -r requirements-test.txt
.venv/bin/ruff check .
.venv/bin/ruff format --check .
.venv/bin/python -m pytest -q
```

Проверено: 26 тестов проходят на Home Assistant 2026.9.1 и Python 3.14.3. Тесты проверяют реальные классы HA, создание устройства и двух сущностей через штатный config flow, а также преобразование команд `python-miio`; сетевой обмен подменяется. Для проверки на устройстве: добавьте лампу, проверьте оба источника света и яркость, измените состояние физической кнопкой и дождитесь опроса. Затем отключите питание, дождитесь недоступности, включите и проверьте восстановление. Проверка на устройстве обязательна перед заявлением полной совместимости с конкретной прошивкой.

## Основа

Интеграция использует [python-miio 0.5.12](https://github.com/rytilahti/python-miio), включая его драйвер Philips EyeCare. Командная утилита `miiocli` не вызывается. Структура интеграции следует [Home Assistant Developer Docs](https://developers.home-assistant.io/docs/creating_integration_manifest/).

Код распространяется по MIT; зависимости сохраняют свои лицензии. Это независимый проект, не официальный продукт Xiaomi или Philips.
